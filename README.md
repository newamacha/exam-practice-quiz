# Exam Practice Quiz

Interactive practice for 9 exams (477 multiple-choice questions): ISMS / ISO 27001 awareness, ISMS knowledge, management documents, SOPs, policy tests and TulipsHRM. Pick an exam, tick an option, and it is marked instantly: a green ✓ when right, or a red ✗ with the correct answer when wrong.

Open it at **https://newamacha.github.io/exam-practice-quiz/**

Your answers are saved in your own browser only.
